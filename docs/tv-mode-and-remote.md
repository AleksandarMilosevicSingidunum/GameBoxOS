# TV Mode and GameBox Remote

TV Mode is an optional dashboard for GameBox running on the HONOR phone’s HDMI display. Use the display button in GameBox’s top navigation to enter it; **Exit TV Mode** returns to the normal GameBox shell. Home prioritizes a featured or last-watched channel, four pinned apps, popular channels, and a Now/Next programme guide. Use **Home layout** to hide or reorder Live TV, Quick launch, and the guide. Pin apps in **Edit apps**; **More apps** opens the installed-app drawer. Supported video services open in GameBox’s embedded browser, while other apps launch through Android and may be displayed as a HONOR freeform window.

## Live TV

On first use, TV Mode automatically saves and loads Serbia’s (`RS`) iptv-org playlist. A previously saved playlist remains selected. To change countries, enter a two-letter code and choose **Browse iptv-org**; **Choose playlist** selects a local M3U file. Duplicate entries are hidden by `tvg-id`, falling back to a normalized channel name; duplicate stream URLs are retained as automatic playback fallbacks. For an iptv-org country playlist, GameBox loads that country’s FreeEPG XMLTV feed; it also accepts an HTTPS `url-tvg`, `x-tvg-url`, or `tvg-url` declared in a custom M3U. Programme IDs are matched directly first, then by conservative normalized channel names to handle provider ID differences. Channel logos are used only when an M3U provides an HTTPS logo URL; otherwise, cards use initials. The channel rail shows favorites first and excludes the featured channel; the Now/Next guide shows programme times and current-programme progress. Selecting a channel plays its playlist URL inside GameBox; the last selected channel is remembered by channel identity without persisting its stream URL. If an RTS 1/2/3 or RTS Svet playlist URL fails, GameBox keeps the failed stream view and its **Retry stream** action available, and offers **Open RTS Planeta** as a separate action. The official page loaded on HONOR TV, but video playback and account access still need acceptance. GameBox does not host or bundle streams. iptv-org describes its playlist entries as user-submitted links and says it cannot control their destinations, availability, or rights; check that a stream is authorized where you live before opening it ([iptv-org/iptv](https://github.com/iptv-org/iptv)).

Pinned Netflix, Prime Video, YouTube, EON, and RTS Planeta cards open their official web versions inside GameBox. Other apps without a mapped web version still launch as Android apps. The embedded browser keeps navigation in GameBox; provider sign-in, DRM, and actual streaming may be limited by WebView support and each provider's rules.

The TV dashboard shows only pinned apps. Choose **Add apps** to search installed apps and pin the ones you want; the list refreshes whenever the manager opens so newly installed apps appear. Choose **Done** to return to the curated dashboard.

## Phone remote

1. In GameBox, open **Settings → Network** and enable **GameBox Companion**. Then choose **Start remote pairing** on the HONOR. The six-digit code is valid for two minutes and accepts at most five attempts; starting a pairing window is the host-side approval. Pairing is needed once per remote phone.
2. Install `companion-remote/build/outputs/apk/debug/companion-remote-debug.apk` on the other Android phone. Keep both phones on the same Wi-Fi.
3. Choose **Find GameBox on Wi-Fi**, enter the temporary pairing code shown in GameBox, then choose **Pair this phone**. The remote stores its token encrypted with Android Keystore and reconnects automatically on later launches; rediscover the host if its local IP changes.
4. Use the D-pad, OK, Back, TV Home, GameBox, and text controls. Text is sent to TV Mode’s app search.

Each remote gets its own random HMAC token, encrypted on the HONOR and Android Keystore-protected on the remote phone. Pairing replaces the previous remote token. GameBox Remote uses plain HTTP on the port immediately after the Windows companion port and is accepted only from loopback or private/link-local addresses; HMAC authentication and replay protection still apply. Because local HTTP does not encrypt traffic, use this only on a trusted Wi-Fi network. The existing Windows companion remains on its TLS endpoint. The remote can revoke its token from its control screen; GameBox can revoke it from Network settings. Disabling GameBox Companion stops both listeners.

If a remembered token is stale or its host is unreachable, the disconnected remote now offers **Forget saved pairing** so it can be paired again without clearing app data. This removes the credential only from the remote phone; use **Disconnect and revoke pairing** while connected to revoke it on GameBox.

Build the two APKs from the repository root with `gradlew.bat :app:assembleDebug :companion-remote:assembleDebug` (Android SDK 36 and JDK 17+ required).
