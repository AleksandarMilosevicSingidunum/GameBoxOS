# GameBox OS — Gaming UX implementation goal

Updated 7 November 2026. This supplements the project goal and the TV Mode/Remote work; it does not replace them.

## Outcome

Deliver a controller-first gaming experience on the HONOR phone connected to a TV. A player can discover or import a game, follow its download and import, configure an emulator, play, return to GameBox, manage saves, and remove or reinstall content with clear information at every step. Match the development blueprint as closely as practical and preserve the normal phone and TV Mode flows.

## P0 — Make the journey reliable and understandable

- [ ] Define truthful game readiness across Home, Library, discovery, details, and Downloads. Distinguish local files, active transfer, import, missing content, emulator setup, and actual launch readiness; do not imply an installed file guarantees an emulator is ready.
- [ ] Show ongoing downloads/imports and tasks needing attention on Home, with an accessible action to the same Download Manager entry. Keep background transfers observable after navigating away; reflect real progress, stages, failure, retry, pause, and cancellation capability.
- [ ] Make every primary flow usable with a controller: D-pad focus and scrolling, A select, B dismiss/back, on-screen search and text entry, dialogs, source pages, import choices, focus restoration, and return from emulators. Verify physical input separately from synthetic input.
- [ ] Surface actionable launch recovery for missing files, unsupported formats, missing emulators or firmware, and early emulator exit. Offer only actions that actually work; preserve game data and saves.
- [ ] Provide clear download/import completion and failure states, including archive extraction, multi-file and multi-disc handling, duplicate choices, storage shortages, integrity checks, and safe cleanup. Move and remove source archives only after verified success and according to the selected policy.
- [ ] Make removal and uninstall confirmations explicitly distinguish game files, archives, saves, metadata, and favorites; protect saves and unrelated content.
- [ ] Continue investigating the HONOR Dock and fullscreen handoff using supported APIs and actual HDMI hardware; document any remaining OEM limit without claiming it is solved.

## P1 — Restructure gaming screens around the player

- [ ] Home: prioritize Continue Playing or a truthful discovery/installed state, active tasks, recently played, collection, and discovery; place PC shortcuts and device status below or outside the primary gaming journey. Provide useful first-run and empty-library actions.
- [ ] Library: improve the console/favorites rail, game grid, card artwork and state, sorting, visible active filters, matching counts, empty states, focus restoration, and larger-library navigation.
- [ ] Search: provide clear global, Library, and discovery scopes; usable controller keyboard, suggestions with explicit correction, recent searches, and results grouped into console rows with source and availability.
- [ ] Discover/Vimm flow: make source and next action clear; keep the game context and Download Manager reachable during source navigation; show truthful start, transfer, import, and recovery feedback. Respect available sources and user-provided copies.
- [ ] Game details: consistently place the state-specific primary action (Play, Download, View download, or setup), favorite, and secondary actions; organize metadata, screenshots, edition/files, emulator, saves, storage, and advanced controls for TV readability.
- [ ] Emulator setup center and per-game selection: show installed/configured/unsupported status, format and firmware requirements, controller mapping guidance, touch overlay settings when supported, and the return path to the game.
- [ ] Save management: show actual accessible save/backup state, manual backup and restore, timestamps, conflict handling, and limitations when an emulator's save location is inaccessible.
- [ ] Artwork and metadata: use neutral fallback artwork, platform-aware matching, confidence and correction controls, a manual artwork picker, and screenshot handling; prevent confident incorrect platform matches.
- [ ] Handle duplicates, multiple discs, different editions, missing companion files, and interrupted import/recovery with clear player choices.
